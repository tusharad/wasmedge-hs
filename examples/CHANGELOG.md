# Changelog for wasmedge-hs-examples

## 0.1.0.0 (2026)

* Initial release.
* `hello`: demonstrates `runWasmBytes` with an inline add module.
* `hostfunc`: demonstrates host function registration via `buildHostModule`.
* `aot`: demonstrates AOT compilation with `WasmEdge.Compiler`.
* `plugin`: demonstrates plugin discovery with `WasmEdge.Plugin`.
